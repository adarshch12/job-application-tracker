# job-application-tracker
A Python based web application to manage and track job and internship applications.
# FEATURES
- Add bew job applications.
- Store company names.
- Track job roles.
- Maintain application status.
- Save application details in a JSON file.
# Technologies used
- Python
- JSON
# Project Structure
- app.py - Main Python application
- jobs.json - Stores job application data
